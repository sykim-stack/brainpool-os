# ADR-HERMES-000 — Hermes Phase 0 Action Unit 경계

_상태: Active_  
_결정일: 2026-10-08_  
_관련: ADR-CONTEXT-000 · ADR-HAJUNAI-CHILD-000 · ADR-CONFIRM-000 · Message-centric_

## 결정 (한 문장)

**Hermes는 “다음에 의미 있는 방향을 발견하는 것”까지만 한다. 실행 Agent가 되지 않는다.**

Phase 0에서는 Action Unit 발생 여부와 5개 행동 후보 선택·제안까지만 담당한다. 실제 실행은 사람 승인 후에만 발생한다.

---

## 1. Action Unit 정의 (고정)

**Action Unit** =
현재의 이해와 새로운 의미 사이에 변화가 생겼고,
그 변화에 따라 다음에 취할 가치가 있는 방향이 하나 이상 생긴 상태.

세 조건이 **모두** 충족되어야만 Action Unit이 발생한다.

| 조건 | 의미 |
|------|------|
| **변화** | 현재 이해에 달라질 가능성이 있다 |
| **필요** | 그 변화 때문에 다음에 뭔가 할 가치가 생긴다 |
| **방향** | 그 “뭔가”를 행동 후보로 표현할 수 있다 |

하나라도 없으면 Action Unit을 만들지 않는다.

---

## 2. 세 단계 분리 (고정)

```text
1. 의미가 생겼다
2. 행동 후보가 생겼다 (Action Unit)
3. 행동이 실행됐다
```

- Hermes는 **2번까지만** 담당한다.
- 3번은 사람 승인 후에만 발생한다.

---

## 3. Phase 0 행동 후보 (고정 · 5개만)

| 행동 후보 | 의미 |
|-----------|------|
| 이해 갱신 후보 | 현재 이해를 바꿀 필요가 있음 |
| 남김 후보 | 원본으로 남길 가치가 있음 |
| 확인 질문 후보 | 이해하기 위해 사람에게 다시 물어야 함 |
| 연결 후보 | 기존 이해·원본과 연결할 가치가 있음 |
| 보류 후보 | 의미는 있지만 지금 행동할 필요는 없음 |

- 더 이상 후보를 추가하지 않는다.
- “보류 후보”는 정상적인 판단 결과로 반드시 존재해야 한다.

---

## 4. 처리 흐름 (고정)

```text
새로운 말
 ↓
의미 판단
 ↓
현재 이해와 관계 있음?
 ↓
이해의 변화 가능성 있음?
 ↓
그 변화 때문에 다음 행동 필요성 있음?
 ↓
Action Unit 발생 여부 결정
 ↓
행동 후보 선택 (0~n개)
 ↓
사람에게 제안 / 대기
 ↓
(승인 시에만) 실제 행동
```

Hermes는 실행하지 않는다. 제안하거나 대기한다.

---

## 5. Phase 0 범위 (In / Out)

### In (Phase 0에서 한다)

- Action Unit 발생 여부 판단
- 5개 후보 중 적절한 것 선택
- 사람에게 제안하거나 대기
- 보류를 정상적인 결과로 처리

### Out (Phase 0에서 하지 않는다)

- 실제 실행 (남기기, 이해 갱신 반영, 질문 발화 등)
- 행동 반복 → 패턴화
- 패턴 → 스킬화
- 스킬 → 재사용
- 후보 목록 확장
- 자동 승인 / 자율 실행

---

## 6. 기준 사례 (수용 기준 · 5개 문장)

| 문장 | Action Unit | 주요 후보 |
|------|-------------|-----------|
| 안녕 | 없음 | 보류 |
| 이건 중요해 | 있음 | 이해 갱신 + 확인 질문 |
| 전에 말한 것과 달라 | 있음 | 이해 갱신 + 연결 + 확인 질문 |
| 이건 기록해줘 | 있음 | 남김 (+ 확인 질문) |
| 잘 모르겠어 | 있음 | 확인 질문 + 보류 |

이 5개가 Phase 0의 수용 기준이다.  
결과가 크게 어긋나면 정의를 다시 검토하고, 어긋나지 않으면 이 경계를 유지한다.

---

## 7. 잠금 선언

위 1~6을 Phase 0 경계로 잠근다.

이 경계를 넘는 논의(패턴화, 스킬화, 후보 추가, 자동 실행)는 **Phase 0이 끝난 뒤에만** 한다.

## 소유권·관련 ADR과의 정렬

| 계층 | 주체 | 비고 |
|------|------|------|
| 원본 | Core | ADR-CONTEXT-000 |
| 이해 | HajunAI | contexts |
| Action Unit 판단·제안 | Hermes (Phase 0) | 본 ADR |
| 실행·확정 | 사람 | ADR-CONFIRM-000 |

Hermes는 이해를 “다음 방향”으로 번역하는 층이다. 이해를 직접 쓰지 않고, 실행도 하지 않는다.

## 하지 않음 (Phase 0)

- 후보 확장
- 패턴·스킬 추출
- 자동 실행
- Hermes를 실행 Agent로 취급
